## 😎Сравнение Flexbox и CSS Grid

### Общая идея

| Критерий | Flexbox | CSS Grid |
|----------|---------|----------|
| **Тип компоновки** | Одномерная | Двумерная |
| **Управление** | Строка или столбец | Строки и столбцы одновременно |
| **Основное назначение** | Выравнивание элементов внутри контейнера | Построение сложных макетов страниц |
| **Подход** | Распределение пространства вдоль одной оси | Создание сетки по строкам и столбцам |
| **Подходит для** | Компонентов, меню, карточек | Страниц, галерей, дашбордов |

**Вывод:** Flexbox лучше подходит для линейных структур и выравнивания элементов в одной плоскости, а Grid — для создания сложных табличных макетов и полных страниц.

### Типичные сценарии использования

| Задача | Рекомендуется |
|--------|---------------|
| Навигационное меню | Flexbox |
| Карточки товаров | Flexbox + Grid |
| Центрирование элемента | Flexbox |
| Макет страницы | Grid |
| Галерея изображений | Grid |
| Дашборд | Grid |

## Ключевые концепции CSS Grid

### Основные понятия
- **Grid-контейнер** — родительский элемент с `display: grid`
- **Grid-элементы** — дочерние элементы внутри контейнера
- **Grid-линии** — разделительные линии между ячейками (нумеруются с 1)
- **Grid-треки** — пространство между двумя соседними линиями (столбец или строка)
- **Grid-ячейки** — пересечение строки и столбца
- **Grid-области** — прямоугольные области из нескольких ячеек

### Основные свойства CSS Grid

```css
.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr; 
    grid-template-rows: 100px auto 100px;
    gap: 20px; 
}

/* repeat() */
.grid-container {
    grid-template-columns: repeat(3, 1fr); /* 3 равные колонки */
}

/* Именованные области */
.grid-container {
    grid-template-areas: 
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

/* Адаптивная галерея */
.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
